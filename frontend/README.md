# Frontend

Admin and user console.

First pages:

- Admin dashboard
- Provider management
- Provider detail and usage
- Public model management
- Public model detail with manual upstream switch
- User management
- API key management
- Request logs
- User usage dashboard

## Stack

- React
- Vite
- TypeScript
- Ant Design
- React Router
- TanStack Query
- Axios
- Zustand

## Run

```powershell
npm install
npm run dev
```
